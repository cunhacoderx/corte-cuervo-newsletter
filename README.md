# 🕸️ Corte Cuervo Newsletter - HTML Email Design

Este projeto é um exercício prático de criação de um template de **email marketing responsivo** utilizando apenas **HTML inline**, com foco em boas práticas de compatibilidade entre clientes de email. O conteúdo é temático, com estilo cyberpunk e narrativa voltada para tecnologia obscura e cibercultura.

---

## ✨ Sobre o Projeto

**Corte Cuervo News** é uma newsletter fictícia inspirada na estética hacker, misturando mistério, tecnologia e narrativa alternativa. O foco está na construção de uma estrutura funcional de email HTML, adequada para ser renderizada por serviços como Gmail, Outlook, Yahoo, etc., respeitando as limitações técnicas desses ambientes.

---

## 🎯 Objetivos Didáticos

- Entender a estrutura e os desafios técnicos de desenvolvimento de **emails HTML**
- Aprender a usar **tabelas**, **estilização inline** e **compatibilidade cross-client**
- Praticar responsividade mínima com uso de **layout fixo e centrado**
- Aplicar **boas práticas visuais** com espaçamentos, hierarquia visual e consistência
- Desenvolver atenção aos **detalhes visuais**, como padding externo entre cards, espaçamento interno (respiro), alinhamento de imagens e coesão tipográfica

---

## 🧠 Conceito Temático

> "Sabedoria das sombras para mentes inquietas."

A newsletter simula uma comunicação sigilosa de um coletivo fictício chamado **Corte Cuervo**, que compartilha informações sobre:

---

## 🛠️ Tecnologias e Técnicas Utilizadas

| Elemento             | Descrição                                                                 |
|----------------------|---------------------------------------------------------------------------|
| `HTML` raíz          | Sem uso de CSS externo ou JavaScript (conforme restrições de email)      |
| `Tabelas`            | Para estruturação do layout em clientes de email antigos                  |
| `Estilo inline`      | Estilização feita diretamente nos elementos para maior compatibilidade    |
| `Imagens fixas`      | Todas com mesmo tamanho para consistência visual                          |
| `Padding e margin`  | Espaçamento entre os cards para dar contraste com o fundo escuro   |
| `Semântica mínima`   | Títulos com `<h2>`/`<h3>`, parágrafos e uso apropriado de `<em>` e `<strong>` |
